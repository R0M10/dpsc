# Цифровая карта личных компетенций

[![Открыть в браузере](https://img.shields.io/badge/github-repo-blue?logo=github&style=for-the-badge)](https://r0m10.github.io/dpsc/)
![W3C Validation](https://img.shields.io/w3c-validation/html?targetUrl=https%3A%2F%2Fr0m10.github.io%2Fdpsc%2F)


### Концепция
Проект представляет собой визуализацию имеющихся навыков и компетенций в виде удобной цифровой копии. 
* **Оценка:** Отражение объективной или субъективной оценки умений.
* **Цель:** Личное ведение, отслеживание, группировка и классификация навыков по областям или сферам.
* **Печать:** Возможность экспорта и вывода на печать в удобной форме (PDF, принтер).

### Стек технологий (Tech Stack)
* **Frontend:** HTML5, CSS3, JavaScript (Vanilla ES-Modules)
* **Архитектура:** Модульная структура (разнесение логики UI и ядра)
* **Тестирование:** Собственная система тестов для проверки целостности сайта (`/tests`)


### Структура проекта
Сайт расположен в корневой папке и имеет следующую структуру:
* `css/`   — файлы стилей
* `js/`    — основная бизнес-логика утилиты
* `js/ui/` — компоненты и логика интерфейса
* `img/`   — превью, иконки и другие изображения
* `tests/` — элементы тестирования сайта и проверки его целостности

### Локальный запуск
Так как в проекте используются современные ES-модули (ES-Modules), для локального просмотра требуется запуск через локальный сервер. Выберите любой удобный вариант:

**Вариант 1: Через Python**
```cmd
cd project/
python -m http.server 8000
```

**Вариант 2: Через Node.js**
```bash
cd project
npx serve
```

**Вариант 3: Через VS Code Live Server**
1. Установите расширение **Live Server** в VS Code.
2. Кликните правой кнопкой мыши по файлу `index.html`.
3. Выберите **Open with Live Server**.

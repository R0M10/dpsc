# Digital Personal Skill Card - Цифровая карта личных компетенций

### Концепция:

Визуализировать имеющие навыки и компетенции в виде удобной цифровой копии.
Отражение максимально объективную оценку умений (На сколько это возможно).
Для личного ведения и слежения, группировки и классификации.
С последующей возможностью вывода на печать в удобной форме. (PDF, Printer)

### Настройки:
Сайт расположен в папке src/
ES-модули запускаются через варианты:

1. через - Python
```cmd
cd project/
python -m http.server 8000
```
2. через Node.js
```bash
cd project
npx serve
```
3. через VS Code Live Server:
Установить расширение Live Server, правый клик по index.html -> Open with Live Server.
